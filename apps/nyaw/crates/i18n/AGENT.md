# crates/i18n

層: 4 UI（横断部品）

アプリケーション画面に表示される文言の国際化（多言語対応: 英語・日本語）を提供する。

言語ごとのリソースファイル（`locales/{en,ja}/messages.toml`）をコンパイル時にバイナリへ埋め込み、GPUI のグローバルリソース `Lang` を通じて動的に文字列を解決する。

## 文言解決とフォールバック規則

- **キーの形式**: ドット区切りの階層構造（例: `settings.general.title`）を用い、変数展開には波括弧 `{name}` を使用する。
- **フォールバック**: 現在の選択言語に指定キーが存在しない場合は英語（`en`）のリソースを参照し、英語にも存在しない場合はキー文字列そのものをフォールバックとして返す。
- **日付・曜日書式**: `date(cx, now)` を通じて言語に応じた日付フォーマット（`common.date`）および曜日表記（`weekday.*`）を提供する。
- **整合性テスト**: CI テストにおいて、すべての言語間でキーセットおよび変数プレースホルダーが完全に一致していること、およびソースコード内の `i18n::t` 呼び出しキーがリソース内に実在することを静的に検証する。

## 主な公開 API

```rust
t(cx, key);                             // 単純な翻訳文字列の取得
tf(cx, key, &[(name, &value)]);         // 変数展開付きの翻訳文字列の取得
date(cx, now);                          // 現在言語に応じた日付文字列のフォーマット
Lang::{
    En, Ja, ALL,
    native_name,                        // 言語自身の母国語表記（例: "English", "日本語"）
    current,                            // 現在の言語取得
};
```
