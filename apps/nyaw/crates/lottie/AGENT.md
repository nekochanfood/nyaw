# crates/lottie

層: 0 基盤

Lottie のアニメーションの再生。JSON を読み、指定したフレームを画素に描き、押した位置にある部品を判定する。GPUI にも、ワークスペースの他のクレートにも依存しない。描画は tiny-skia、曲線の計算（トリム、当たり判定の線の太らせ）は kurbo で行う。

## 主な公開 API

- `Animation::from_json(&str)`: 読み込む。対応しない機能を使っていれば `Error::Unsupported` を返す（黙って描画を崩さない）。
- `Animation::render(frame, width, height) -> Option<Pixmap>`: 合成の全体を `width` × `height` に合わせて描く。画素は乗算済みの RGBA。
- `Animation::hit(frame, x, y) -> Option<String>`: 合成の座標で、`cl` の付いた塗りか線のうち、手前にあるものの `cl` を返す。型やマスクによる切り抜きは考えない。
- `Animation::marker(name)`: 名前の付いた区間（Lottie のマーカー）。
- `Animation` は `Send` + `Sync` なので、描画はバックグラウンドスレッドで行える（画面の部品は `design::lottie` を参照）。

## 対応する機能

nyaw のアニメーション（リポジトリルートの `assets/animations/`）が使う機能だけに対応する。

- 層: シェイプレイヤー（`ty: 4`）とプリコンポ（`ty: 0`）。変形（アンカー、位置、拡大率、回転）、表示の始まりと終わり（`ip`、`op`）、開始のずれ（`st`）。
- 切り抜き: 足し合わせのマスク（`mode: "a"`）と、アルファマット（`tt: 1`、反転は `tt: 2`）。
- シェイプ: グループと変形、パス（形のキーフレームは頂点の数が同じときだけ補間）、楕円、角の丸くない矩形、塗り（非ゼロと偶奇）、線（端と角）、トリム（「同時に」のみ）。
- 値: 静止値とキーフレーム（3 次ベジェのイージングとホールド）。イージングは全成分で共通の 1 本。
- マーカー（`markers`）と、塗りや線の `cl`。

不透明度（層、グループ、塗りや線の `o` のキーフレーム）は、塗りや線の色に掛ける以外は扱わない。親子関係（`parent`）、テキスト、画像、エフェクト、角丸、リピーターなどは `Error::Unsupported` にする。プリコンポは自分の範囲（`w`、`h`）で切り抜かない（`ponytail:` を参照）。

## Lottie の規則の要点

- 項目は前にあるものほど手前に描く。塗りや線は、同じグループの中でそれより前にある形（入れ子のグループの形を含む）に掛かる。トリムも、それより前にある形を切る。
- 線の太さは、線の項目があるグループの変形の拡大率に合わせて太らせる（縦横で違う拡大率は、面積の比の平方根で近似する）。
- 型（`td: 1`）は、すぐ下の層（`tt` を持つ層）の切り抜きにだけ使い、自分は描かない。

## テスト

- 単体テスト: 値の補間とイージング、トリム。
- `tests/logo_full.rs`: `assets/animations/logo-full` を読み、マーカー、最初のフレームが空であること、しっぽが出る前とイントロの最後に絵が左右の中央にあること、イントロの最後のフレームが静止画のロゴ（resvg で描く）とほぼ同じこと、押した位置の判定を確かめる。

```sh
cargo test -p lottie
```
