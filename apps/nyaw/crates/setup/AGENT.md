# crates/setup

層: 5 画面

初回起動時に必要な初期設定をステップ形式で案内するセットアップウィザードを提供する。

ナビゲーションバーを持たない単一の大判パネル（1.152m × 0.864m、4:3 比率）として構成され、文字盤選択などの大型コンテンツが収まるよう設計されている。二枚目以降の操作エリアは最大幅 704px の中央列に配置され、下端両脇に「戻る」および「次へ」ボタンを備える。

## セットアップ手順（Step）

ウィザードは以下の順序で進行する。二枚目以降は「戻る」ボタンによる前手順への復帰が可能である（誤操作を防ぐため、スワイプバックは無効化されている）。

| 手順 | 設定項目 | 操作インターフェース |
|---|---|---|
| `Welcome` | 言語選択・開始 | アプリロゴ、歓迎メッセージ、概要を表示。右下に「次へ」、左下に終了ボタン（`setup-quit`）および上方向展開の言語選択ドロップダウン（`setup-language`）を配置。 |
| `Hand` | 利き手の指定 | 左手 / 右手をカード選択（`components::choice`）で決定。 |
| `Accessibility` | 文字サイズ・UI スケール・太字 | 設定画面と共通の部品（`ui::prefs::accessibility`）。外観設定に先立ち、視認性の基盤を決定する。 |
| `Appearance` | テーマとアクセントカラー | 設定画面と共通の部品（`ui::prefs::appearance`）。テーマ選択とカスタムカラー作成ダイアログ。 |
| `Wrist` | 腕時計パネルの文字盤 | 設定画面と共通の部品（`ui::prefs::watch_faces`）。文字盤デザインのカルーセル選択。 |
| `AutoLaunch` | SteamVR 連動起動 | **OpenVR 環境でのみ表示**。「SteamVR と同時に起動」または「手動で起動」を選択。未選択時は SteamVR への登録を行わない。 |
| `Done` | 完了 | アイコン・見出しと、左手のショートカット（ダッシュボードを開くボタン）を 2 回押すよう促す説明。下に左手で使用中のコントローラ（無ければ Quest Touch Plus）を寄って映し（`guide::zoom`）、そのボタンをダブルタップの波紋（2 つずつ、押すと沈みながら現れ、離すと広がって消える）で示す。コントローラは完了画面に入ると下から上がりつつ現れる。画像は上端で地へ溶かし、見出しと重なっても読める。「完了」ボタンは無く、左下に「戻る」。**開発ビルドのみ**右上に映す機種を切り替えるドロップダウン（`setup-controller`）。 |

### 設定値の反映とライフサイクル

- **即時反映**: 各手順で選択した設定値は、即座に `Setting` コマンドとして発行されてシステムへ適用される。「次へ」を押さずに「戻る」で戻った場合でも、変更した設定は保持される。
- **ロックダウンの適用**: ウィザード起動時は `PanelSpec::lockdown()` によりロックダウンを取得する。ウィザード表示中は手首パネルおよびダッシュボードが非表示化され、誤操作による閉塞が防止される。完了画面に入るとロックダウンを解き（戻るとかけ直す）、ショートカットの二回押しで wrist がダッシュボードを開けるようにする。
- **完了**: 完了画面でショートカットが二回押される（`PanelStatus::double_press` が増える）と、`SetupDone(true)` と `Lockdown(false)` を発行してパネルを閉じる。同じ押下で wrist がダッシュボードを開く。あわせてチュートリアルを頼み（`ui::tour::start`）、開いたダッシュボードで案内が始まる（[`dashboard`](../dashboard/AGENT.md) の「チュートリアル」）。押下を見るのは `SetupWizard::build` で作ったとき（`spec` / `spawn_spec`）。
- **頭部追従（LazyFollow）**: ウィザードパネルは頭部前方の 1.5m の位置に緩慢追従（`LazyFollow`）し、ユーザーの頭部回転に滑らかに追従する。
- **初回完了フラグ**: ウィザードを完了すると `Setting::SetupDone(true)` が設定ファイルへ書き込まれる。途中で終了した場合、選択済みの設定値は保持されるが、次回起動時に再度ウィザードが呼び出される。

## 主な公開 API

```rust
setup::spec();               // 初回起動用のパネル起動仕様
setup::spawn_spec(from);     // デバッグ画面からの再実行用仕様
setup::follow();             // 頭部追従パラメータの取得
SetupWizard::build(id, cx);  // パネルとして開くウィザード（ショートカットの二回押しを見る）
SetupWizard;                 // ウィザード状態管理構造体（`new` は押下を見ない。描画の検証用）
Step;                        // 手順の列挙型
STEPS;                       // 全手順の定義配列
shown(step, settings);       // ランタイムに応じた手順表示判定
```

## テスト手法

- **通し操作テスト (`crates/testkit/tests/scenarios/setup.rs`)**: 全ステップの進行、言語切り替えによるテキスト即時更新、終了確認ダイアログの動作、OpenVR 固有手順の表示制御、子ダイアログ展開時の排他入力、および完了画面で X を二回押すと完了することを検査する。
- **ロックダウンと追従テスト (`setup_lockdown.rs`)**: ロックダウン発効時の他パネル退避および頭部追従の動作、完了画面でのロックダウン解除、使用中の機種（レンダーモデル名を偽装）のボタンを示すことと開発用ドロップダウンでの切り替えを検証する。
- **完了画面の機種ごとの映り方**: `cargo test -p ui --test gpu -- guide` が全機種の完了画面を `target/tmp/guide-done-*.bmp` に書き出す。
- **実描画検証**: `cargo test -p ui --test gpu -- --ignored look` を通じて、各ステップの描画画像（`target/tmp/look-setup-*.bmp`）を出力してレイアウト崩れがないことを確認する。
