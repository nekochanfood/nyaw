ダッシュボード。左手の X ボタン（Touch は X、Index は左手の A、novr はキーボードの X、コントローラの無い手は手のひらを顔に向けて親指と小指を 0.5 秒付け続ける）を `kernel::DOUBLE_PRESS`（250ms）以内に二回押すと開き（カーネルは画面を知らず、左手の X をショートカットボタンとして `PanelStatus::double_press` に数えるだけ。開くのは wrist）、もう一度二回押すと閉じる。開いている間は空間全体が暗くなる（`PanelSpec::with_veil`）。ダッシュボードは少し上を向けたバー（`Dashboard`。掴んで動かせる）そのもので、開いた時は何も出さない。はめた画面が目の高さの正面 1.1m に垂直に立つよう、バーはその下に置く（`dashboard::pose`。オーバーレイの `slot` の置き方の逆算。`overlay::SLOT_GAP` と `ui::NAV_BAR_HEIGHT_M` を使う）。左からメニュー（`dashboard-menu`。バーに固定したポップオーバー `Menu`（`PanelSpec::popover`）を左端の上に出し、デバッグ（`menu-debug`。main が渡す画面。今は Testing）・設定（`menu-settings`。main が渡す画面。今は Testing の設定画面）を選ぶ。一番下の終了（`menu-quit`）は視界の中央に確かめのダイアログ（`quit-confirm` / `quit-cancel`）を出してアプリを終える。背景は敷かず一覧のカードがそのまま出る。外側を押すと閉じる）・時刻（幅は数字によらず固定）と HMD の電池（`dashboard-quick-settings`）・何か再生しているときだけ再生中（`dashboard-now-playing`。playlist のアイコン）・画面やウィンドウを開く「+」（`dashboard-mirror`。一覧を出す）、区切り線を挟んで開いた配信のボタン（`dashboard-stream-<PanelId>`。画面はモニター、ウィンドウはアプリのアイコン。溜まっていき、はみ出すと横にスクロールする。押すとその配信がはまり、はまっていた配信は閉じずに隠して外す（そこへ打つキーボードは片付ける）。もう一度押すと隠す。配信を閉じる・自分で外して独立させるとボタンは消える）。閉じるボタンは置かない。ボタンを押すとその画面（自分のナビゲーションバーを持つ別のパネル）をバーの上にはめ（`ui::dock`。はまっていた画面は閉じる）、同じボタンをもう一度押すと閉じる。はまっている画面のボタンは強調色。はめた画面はダッシュボードに固定され（一緒に動き、掴むとダッシュボードごと動く）、ナビゲーションバーの `nav-undock` で外して独立させ（手前へ離れる）、`nav-dock` で戻せる。閉じる（X ボタンの二回押し・出ている間にダッシュボードにもほかのパネルにも当たらない所でトリガーを押す（`PanelStatus::outside_press`））と、はめた画面ごと隠すだけ（`dashboard::hide`。配信も止めない）で、次は同じ状態で目の前に出る（`dashboard::show`）。画面（`Page`）: ミラーリング（`Screen`）= 画面（モニターのアイコン）とウィンドウ（アプリのアイコン）のタイル（`dashboard-source-N`）をグリッドで並べ、押すと配信のパネルが一覧と入れ替わりにはまり、バーに配信のボタンが増える（OS キーボードはバーの下に固定されて出る。画面を外すと一緒に外れる）。再生中（`Screen`）= ジャケットをぼかした背景に、背景の明るさで明暗を選んだテーマの地を薄く重ね、左上に背景の無いアプリのボタン（`now-playing-app`。アイコンは OS から取れなければ同じアプリのウィンドウのもの。押すと そのアプリのウィンドウを配信としてはめ、見つからなければバックエンドの能力に応じてアプリを前に出す）、中央に上からジャケット・タイトル・アーティスト・ハンドルの無い無彩色のシークバー（`now-playing-seek`。押した位置へ移る）・左端に再生位置と右端に長さ・背景の無い前へ / 再生・一時停止 / 次へ。クイック設定（`Screen`）= 上に時刻（幅は固定）・日付と設定ボタン（`quick-settings-open`。バーの設定ボタンと同じ）、テーマの切り替え（`quick-theme`）、デバイスの電池のカード（`battery-hmd` / `-left` / `-right` / `-tracker-N`。HMD・左・右・トラッカーの順） ランチャーは見出しとタイルの行を 1 本の仮想化したリスト（GPUI の `list`。見えている行だけを組み立てる）に並べ、上から「ニャプリ」（入っているニャプリのタイル `dashboard-nyapp-<id>`。押すとランチャーと入れ替わりにはまる。`dashboard-nyapps-update` で更新を確認、`dashboard-nyapps-remove` で消す状態。`crates/nyapp/AGENT.md`）・起動中のアプリ・すべてのアプリ（アプリ一覧は取得に数秒かかるので、ダッシュボードの起動時に読んでおく。アイコンの変換も別スレッド。描き直しの重さは `cargo test -p dashboard --lib launcher_redraw_cost -- --ignored --nocapture`）。バーのクイック設定と再生中の間に、ニャプリの進行中の作業の知らせ（`dashboard-activity-<id>`。タイマーの残りなど。押すとニャプリがはまる）。
