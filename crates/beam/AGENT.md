# crates/beam

層: 6 画面

コントローラのビーム。手ごとにレーザー（線）とカーソル（パネルに貼り付く円）とドラッグの見た目（ドラッグ中だけ。中身は `ui::drag_preview` で包んだビューを GPUI が描き、パネルの外・ウィンドウをまたいでも見える）とツールチップ（カーソルの子。指している要素が `.tooltip(..)` で置いた説明を、頭から見て手の側（`kernel::Anchor`。手が下なら下）にスライドで出す。離れても 0.125 秒は残り、その間に別の要素を指すと文字と幅が変わる）の 4 枚。見た目だけを描き、置き場所・長さ・表示・描画順は `PanelSpec::pointer` で役割を与えたオーバーレイ層が毎 tick 決める（ヒット判定の対象外）。どのランタイムでも載せる（novr のレーザーは視線と重なって見えない）

## 主な公開 API

`beam::specs()`, `Laser`, `Cursor`, `DragLayer`, `Tooltip`（`tooltip::State`）
