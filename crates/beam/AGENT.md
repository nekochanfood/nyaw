# crates/beam

層: 5 画面

VR コントローラのポインタ光線、カーソル、ドラッグ操作中のプレビュー、ツールチップ、および画面ドッキング時のガイド枠の描画を担当する。

本クレートは視覚表現の描画のみを担い、空間座標、光線長、可視性、および描画順序はオーバーレイ層（`PanelSpec::pointer`）が毎フレーム制御する。当たり判定からは除外される。

## ポインタを構成する 5 つの視覚要素

各コントローラに対して以下の要素が独立して描画される。

1. **レーザー光線 (`Laser`)**: コントローラ先端から照射されるポインタ線分。手元側の端は丸める。テクスチャは横だけがレーザーの見える長さに伸びるので、丸みは設定の長さ（`laser_length`）から横の半径を割り戻した半楕円で描き、空間で半円に見えるようにする（設定より近くを指してレーザーが縮むと、丸みも横に縮む）。novr 環境では視線と同一線上に重なるため視認されない。
2. **カーソル (`Cursor`)**: パネル表面との交差点に吸着する円形インジケーター。システム設定 `cursor_scale` の倍率が適用される。
3. **ドラッグプレビュー (`DragLayer`)**: 要素のドラッグ中のみ表示されるプレビューレイヤー。GPUI ウィンドウの描画境界を越えて視覚表示を維持する。
4. **ツールチップ (`Tooltip`)**: カーソルに追従する補助説明表示。頭部から見たコントローラの方向へ展開される。ポインタが要素から外れても 0.125 秒間は表示を維持し、連続した要素移動時のちらつきを防止する。
5. **ドッキングガイド (`DockGhost`)**: 画面パネルの掴み移動中にスロット位置へ出現する吸着見本枠。角丸の四隅フレーム（角枠）と現在の吸着状態（「離してくっつける」「引っ張って外す」など）を示すヒント行を表示する。

## 角枠（`bracket`）

角丸矩形の隅だけを、丸みとそこから辺に沿って少し（`ARM_PX` = 40px）伸ばした線で囲む部品。ドッキングガイドが使い、同じ見た目の線を出すものもこれを使う。

- **共有する値**: 線の太さ（`design::BRACKET_LINE_PX`）とパネル面から角枠の外側までの幅（`design::BRACKET_PAD_PX`。面と線の間に線の太さの 2 倍の隙間を空ける）は、オーバーレイ層も配置に使うので `design` に置く。
- **線の端**: 丸める（`LineCap::Round`。GPUI が再エクスポートしないので lyon を直接使う）。
- **色**: `bracket::color` が、強調する（ドッキングが成立する）なら強調色、それ以外は無彩色を返す。
- **検証**: 線端とレーザーの手元側の端が丸いことは、`ui` の GPU テスト（`cargo test -p ui --test gpu -- stroke_caps`）が実際に描いた画素で確かめる。

## 主な公開 API

```rust
beam::specs();           // ポインタ関連パネル仕様の一括生成
Laser;                   // レーザー光線描画コンポーネント
Cursor;                  // カーソル描画コンポーネント
DragLayer;               // ドラッグプレビュー管理
Tooltip;                 // ツールチップ表示制御
DockGhost;               // ドッキング吸着ガイド枠
bracket::frame(corners, color); // 角枠の要素（隅を選んで描く）
```
