# crates/beam

層: 5 画面

コントローラのビーム。手ごとにレーザー（線）とカーソル（パネルに貼り付く円）とドラッグの見た目（ドラッグ中だけ。中身は `ui::drag_preview` で包んだビューを GPUI が描き、パネルの外・ウィンドウをまたいでも見える）とツールチップ（カーソルの子。指している要素が `.tooltip(..)` で置いた説明を、頭から見て手の側（`kernel::Anchor`。手が下なら下）にスライドで出す。離れても 0.125 秒は残り、その間に別の要素を指すと文字と幅が変わる）と、はめられる画面を掴んでいる間のはまる所の見本（`DockGhost`。`dock.rs`。画面の地と同じ大きさの、強調色の破線の枠だけ（中は透ける）。上の帯に一行（はまっていれば「引っ張って外す」、外れていれば「近づけてくっつける」。`PanelStatus::dock_hint`）。出入りのフェードはオーバーレイ層がランタイムの不透明度で付けるので、描き直すのは一行が変わったときだけ）の 5 枚。見た目だけを描き、置き場所・長さ・表示・描画順は `PanelSpec::pointer` で役割を与えたオーバーレイ層が毎 tick 決める（ヒット判定の対象外）。どのランタイムでも載せる（novr のレーザーは視線と重なって見えない）。カーソルの大きさの設定（`cursor_scale`）はオーバーレイ層がカーソルの幅に掛け、ツールチップはその倍率で大きくなった輪の外に箱を出す。ツールチップを切る設定（`tooltips`）では UI 層が要求を渡さないので出ない

## 主な公開 API

`beam::specs()`, `Laser`, `Cursor`, `DragLayer`, `Tooltip`（`tooltip::State`）, `DockGhost`（`dock::spec`）
