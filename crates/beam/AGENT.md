# crates/beam

層: 5 画面

VR コントローラのポインタ光線、カーソル、ドラッグ操作中のプレビュー、ツールチップ、および画面ドッキング時のガイド枠の描画を担当する。

本クレートは視覚表現の描画のみを担い、空間座標、光線長、可視性、および描画順序はオーバーレイ層（`PanelSpec::pointer`）が毎フレーム制御する。当たり判定からは除外される。

## ポインタを構成する 5 つの視覚要素

各コントローラに対して以下の要素が独立して描画される。

1. **レーザー光線 (`Laser`)**: コントローラ先端から照射されるポインタ線分。novr 環境では視線と同一線上に重なるため視認されない。
2. **カーソル (`Cursor`)**: パネル表面との交差点に吸着する円形インジケーター。システム設定 `cursor_scale` の倍率が適用される。
3. **ドラッグプレビュー (`DragLayer`)**: 要素のドラッグ中のみ表示されるプレビューレイヤー。GPUI ウィンドウの描画境界を越えて視覚表示を維持する。
4. **ツールチップ (`Tooltip`)**: カーソルに追従する補助説明表示。頭部から見たコントローラの方向へ展開される。ポインタが要素から外れても 0.125 秒間は表示を維持し、連続した要素移動時のちらつきを防止する。
5. **ドッキングガイド (`DockGhost`)**: 画面パネルの掴み移動中にスロット位置へ出現する吸着見本枠。角丸の四隅フレームと現在の吸着状態（「離してくっつける」「引っ張って外す」など）を示すヒント行を表示する。

## 主な公開 API

```rust
beam::specs();           // ポインタ関連パネル仕様の一括生成
Laser;                   // レーザー光線描画コンポーネント
Cursor;                  // カーソル描画コンポーネント
DragLayer;               // ドラッグプレビュー管理
Tooltip;                 // ツールチップ表示制御
DockGhost;               // ドッキング吸着ガイド枠
```
