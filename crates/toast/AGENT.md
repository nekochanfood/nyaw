# crates/toast

層: 5 画面

OS の通知（`kernel::Kernel::notifications`。[`crates/subsystems/notifications`](../subsystems/notifications/AGENT.md)）のトースト。**1 枚のパネルを使い回し**、届いた通知を視界の端（HUD）→ 手首の時計の上 → ダッシュボードの上へ動かす。開くのは wrist（起動時に隠したまま。`toast::spec(wrist, opened)`。ID は `Wrist::toast`）。ナビゲーションバーは付けない（常駐で、置き場所は自分で決める。閉じる・動かす対象ではない）。

## 主な公開 API

`spec(wrist, opened)`, `Toast`（`place`）, `Place`, `hud_pose(anchor, safe, scale)`, `HUD_DISTANCE`（1.5m）, `RES_PX`

## 流れ（ウォーターフォール。`flow.rs`）

通知ごとに段階（HUD → 手首 → ダッシュボード → 済み）を持ち、進むだけで戻らない。置き場所はその時の周りから毎フレーム決める。

| 周り | 置き場所 | 出す通知 |
|---|---|---|
| ダッシュボードが出ている | ダッシュボードの上（はめた画面があればその上。`Parent::stack`） | 済みでないものすべて（ダッシュボードの段階へ進める） |
| 時計を見ている（`PanelStatus::gazed`。目を離しても 1.5 秒は残す） | 手首の時計の上（`Parent::slot`、顔の方へ 0.3rad 起こす） | HUD・手首の段階のもの（手首の段階へ進める） |
| 最後に届いてから 6 秒以内 | 視界の端（設定の `notification_anchor`） | HUD の段階のもの |
| それ以外・ロックダウン中 | 隠す | ― |

- ダッシュボードが隠れると、ダッシュボードの段階のものは済みになる（一度でもダッシュボードで見たものは、もう HUD にも手首にも出さない）。HUD の時間が過ぎても、見ていない通知は手首で待つ。OS の通知センターから消えた通知は落とす。
- **動き**: 先へ進むとき（HUD → 手首・HUD → ダッシュボード・手首 → ダッシュボード）は、見えたまま滑らかに動き、大きさも動きの中で変わる（オーバーレイ層の `Glide`。親を移した後に `FitHeight`）。それ以外（手首から目を離した後に新しい通知が HUD に出るなど）は、隠して消えきってから（0.2 秒）出し直す（戻るようには動かさない）。隠すときは親から外す（親を出し直したときに一緒に出ないように）。
- 見た目の大きさがどこでもダッシュボードの画面くらいになるよう、置き場所ごとに密度（px/m）を変える: HUD 600（1.5m 先。視界の端でも気づけるよう少し大きく）・手首 3000・ダッシュボード 1000。

## 見た目と操作

- **HUD**: アイコンと見出し（1 行）だけのカプセル（`toast-hud-<id>`）を、設定の端に寄せて新しいものほど端の近くに並べる（3 つまで。多ければ「ほか n 件」`toast-more`）。押せない（レーザーが素通りする。`PanelCommand::PassThrough`）。
- **手首・ダッシュボード**: カード（`toast-<id>`）にアイコン・見出し・アプリの名前・本文（2 行で省略）。下に寄せ、新しいものほど下（立てた所の近く）。3 枚まで。ホバーすると本文が 6 行まで伸び、通知のボタン（`toast-action-<id>-<番号>`）が並ぶ。押すと本文・ボタンのとおりに開き（URL は `design::link::open` で確かめてから。ほかは `PanelCommand::Notification` でアプリへ届ける）、その通知はもう出さない。
- アイコンが無いアプリは鐘のアイコン。

## HUD のセーフエリア

HUD の中身の外側の端（パネルの端から影の余白の内側）を、両目に確実に映る範囲（`vr::Fov::safe`。ランタイムが教える視野の 60% かつ左右 25°・上下 20° まで。分からなければ片側 40° の HMD とみなす。`../subsystems/vr/AGENT.md` の「HUD のセーフエリア」）の端に合わせ、`HUD_DISTANCE` 先に置いて頭の方へ向ける（`hud_pose`）。UI スケールで大きくなっても端は外へ出ない。

## テスト

`cargo test -p toast`: 流れ（`flow::tests`）、置き場所への動かし方・戻る向きは隠してから・押したときの届け方（`tests.rs`）、HUD がどの端・どの UI スケールでもセーフエリアの端に収まること（`the_hud_stays_inside_the_safe_area`）。見た目は `cargo test -p ui --test gpu -- --ignored look`（`target/tmp/look-toast-*.bmp`）。
