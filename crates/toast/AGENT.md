# crates/toast

層: 5 画面

OS の通知（`kernel::Kernel::notifications`。[`crates/subsystems/notifications`](../subsystems/notifications/AGENT.md)）のトースト。**1 枚のパネルを使い回し**、届いた通知を視界の端（HUD）→ 手首の時計の上 → ダッシュボードの上へ動かす。開くのは wrist（起動時に隠したまま。`toast::spec(wrist, opened)`。ID は `Wrist::toast`）。ナビゲーションバーは付けない（常駐で、置き場所は自分で決める。閉じる・動かす対象ではない）。

## 主な公開 API

`spec(wrist, opened)`, `Toast`（`place`）, `Place`, `hud_pose(anchor, safe, scale)`, `HUD_DISTANCE`（1.5m）, `RES_PX`

## 流れ（ウォーターフォール。`flow.rs`）

通知ごとに段階（HUD → 手首 → ダッシュボード → 済み）を持ち、進むだけで戻らない。置き場所はその時の周りから毎フレーム決める。

| 周り | 置き場所 | 出す通知 |
|---|---|---|
| ダッシュボードが出ている | ダッシュボードの上（はめた画面があればその上。`Parent::stack`） | 済みでないものすべて（ダッシュボードの段階へ進める） |
| 時計を見ている（`PanelStatus::gazed`。目を離しても 1.5 秒は残す） | 手首の時計の上（`Parent::slot`、顔の方へ 0.3rad 起こす） | HUD・手首の段階のもの（手首の段階へ進める） |
| 最後に届いてから 10 秒以内 | 視界の端（設定の `notification_anchor`） | HUD の段階のもの |
| それ以外・ロックダウン中 | 隠す | ― |

- ダッシュボードが隠れると、ダッシュボードの段階のものは済みになる（一度でもダッシュボードで見たものは、もう HUD にも手首にも出さない）。HUD の時間が過ぎても、見ていない通知は手首で待つ。OS の通知センターから消えた通知は落とす。
- **場所を移る動き**: どの移動も、今の場所で前の中身のまま消えきって（アウト。0.2 秒と少しの余裕）から次の場所へ瞬間的に移り、そこで現れる（イン）。見えたまま滑らせると、目の前を横切って視界を遮るので。パネルの出入りは不透明度だけ（`PanelCommand::FadeOnly`。縮めたり奥へ下げたりしない）で、動きは中身が描く: カードのまとまりが、手首・ダッシュボードでは下から上に入って上から下に出る。HUD では寄せた端の外から入り、外へ出る。消えきったら親から外す（親を出し直したときに一緒に出ないように）。
- 見た目の大きさがどこでもダッシュボードの画面くらいになるよう、置き場所ごとに密度（px/m）を変える: HUD 600（1.5m 先。視界の端でも気づけるよう少し大きく）・手首 3000・ダッシュボード 1000。

## 見た目と操作

- **並べ方**: どこでも新しいものが上。足されたカードは上から落ちてきて、高さが伸びながら下のカードを押し下げる（`design::components::slide`。下の端に寄せた HUD では上へ押し出す）。無くなったカードは縮んで消える。3 つまでで、多ければ並べたカードの下に「ほか n 件」（`toast-more`。カードと重ならないよう同じ隙間を空ける）。
- **HUD**: アイコンと見出し（1 行）だけのカプセル（`toast-hud-<id>`）を、設定の端に寄せる。押せない（レーザーが素通りする。`PanelCommand::PassThrough`）。
- **手首・ダッシュボード**: カード（`toast-<id>`。中身は `ui::notification::card`。クイック設定の一覧と同じ）にアイコン・見出し・アプリの名前・本文（2 行で省略）。下（立てた所）に寄せる。ホバーすると本文が 6 行まで伸び、通知のボタン（`toast-action-<id>-<番号>`）が並ぶ。押すと本文・ボタンのとおりに開き（URL は `design::link::open` で確かめてから。ほかは `PanelCommand::Notification` でアプリへ届ける）、その通知はもう出さない。
- **スワイプで片付ける**（`swipe.rs`）: 手首・ダッシュボードのカードは、マウスのドラッグ（押して 8px 動かしてから）でもタッチの方式の指のスライド（横のスクロール）でも左右に付いてきて、離れるほど薄くなる。離したときに幅の 3 割を超えていれば横へ抜けてその場で片付き（もう出さない）、超えていなければ戻る。押したことにはせず、OS の通知センター・クイック設定の一覧からも消さない。
- アイコンが無いアプリは鐘のアイコン。

## HUD のセーフエリア

HUD の中身の外側の端（パネルの端から影の余白の内側）を、両目に確実に映る範囲（`vr::Fov::safe`。ランタイムが教える視野の 40% かつ左右 15°・上下 12° まで（目をほとんど動かさずに読める所）。分からなければ片側 40° の HMD とみなす。`../subsystems/vr/AGENT.md` の「HUD のセーフエリア」）の端に合わせ、`HUD_DISTANCE` 先に置いて頭の方へ向ける（`hud_pose`）。UI スケールで大きくなっても端は外へ出ない。

## テスト

`cargo test -p toast`: 流れ（`flow::tests`）、どの移動もアウトしきってから移ってインすること・新しいカードが上・「ほか n 件」がカードに重ならない・押したときの届け方・スワイプで片付き押したことにならず一覧に残ること（`tests.rs`）、スワイプの閾値（`swipe::tests`）、HUD がどの端・どの UI スケールでもセーフエリアの端に収まること（`the_hud_stays_inside_the_safe_area`）。見た目は `cargo test -p ui --test gpu -- --ignored look`（`target/tmp/look-toast-*.bmp`）。

VR の経路を丸ごと通す E2E は `cargo test -p testkit --test notifications`（実時間に頼るので `scenarios` とは別のバイナリで、1 つずつ流す）: 時計を下ろしていると HUD に出て押せない → 時計を顔の前に上げると HUD で消えきってから手首の上に現れる → X の二回押しでダッシュボードの上へ → ホバーでボタンが出て、押すとアプリへ届く → 閉じるともう出ない。HUD は 4 種の視野の HMD（狭い・Quest 風・Index 風・広い）で四隅どれでも、両目に映り、セーフエリアの端に来る。実ランタイム（Monado・SteamVR の null ドライバ）が視野を返し、セーフエリアがその内側に収まることは `cargo test -p testkit --test runtimes -- --ignored`（`fov_is_reported`）。
