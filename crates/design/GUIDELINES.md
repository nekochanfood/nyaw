# デザインガイドライン

VR 空間のパネルをレーザーで操作する前提の方針。値は `tokens.json` が唯一の情報源で、ここには使い方の規則だけを書く。Web は対象外。

優先順位: **押しやすさ > 読みやすさ > 動きの統一**。

## 押しやすさ

- ヒット領域は最小 **48px**。見た目が小さくても、当たり判定は 48px 以上にする。
- 隣り合う操作対象の間隔は `spacing::SM`（8）以上。
- ホバー・押下・フォーカスは色で区別する。ホバーを見なくても操作が成立すること（押す前にホバーされるとは限らない）。
- 破壊的な操作は `danger` 色にし、他の操作の近くに置かない。

## 読みやすさ

- 文字は `font_size::SM`（14）未満にしない。本文は `MD`（19）を基本にする。
- 文字色は `neutral-text`（7:1）か `text-low`（4.5:1）。組み合わせのコントラストは build.rs が検証するので、`contrast` に無い組み合わせを新しく使うときは表に足す。
- 背景が透ける前提なので、`panel` の不透明度を落としすぎない。

## 動きの統一

- 動きは `animation::Motion`（Enter / Exit / Return / Move）の 4 種だけ。
- 時間は `duration_ms` から選ぶ: 状態変化（ホバー等）= `fast` / `quick`、出入り = `normal`、大きな移動 = `slow`。
- 動きは毎フレームの描き直しを伴うので、不要な動きは足さない。

## 角丸

小さな部品 = `sm`、ボタン = `md`、パネル = `lg`、スイッチ・つまみ = `full`。
