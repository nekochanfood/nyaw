# crates/design

層: 4 UI（横断部品）

UI の見た目の責務。Radix Colors のエイリアスに倣う 3 層。Constants（`scale::{light,dark}::SLATE_1..12` / `BLUE_*` / `RED_*`、`scale::{WHITE,BLACK}`、`radius` / `spacing` / `font_size` / `letter_spacing` / `duration_ms`。段ごとに用途が決まった 12 段の生の値）→ Utilities（`Theme`。`accent` → `blue` のスケールの別名と段の用途名 `accent_solid` など、テーマで指す先が変わる `background`（パネルの地）/ `card` / `control`（ボタンの既定）/ `groove`（スライダーの空き）/ `track` / `on_accent` など。`Mode::{Dark, Light}` と `Theme::of`。部品は役割だけを見る）→ Components（`button` / `switch` / `slider` / `panel` + `card`（カード複数）/ `card_panel`（カード 1 枚）/ `navigation`（画面の積み重ね。右から入る push 遷移と、押したまま右から左へ動かすスワイプバック。タッチ・マウスとも。中の要素が止めた入力は奪わず、縦の一覧は `restrict_scroll_to_axis()` を付ける）/ `dialog`（子パネルの中身: アイコン・タイトル・概要・ボタン）/ `nav_bar`（パネルの下に付くナビゲーションバー: 中央にタイトル、右端に閉じるボタン `nav-close`。持ち主のパネル（かバー）を指していない間は丸い線に縮み、指すと広がる）/ `list` + `list_item`（カード色の行を区切り線で並べる一覧）/ `menu_item`（`>` の無い行。メニュー用）/ `tile`（地に直接並べる押せるカード。グリッド用。中身は呼び出し側が足す。`Button` は `ParentElement` なので中身を足せる）/ `select` + `select_option` + `select_popover`（複数から 1 つ選ぶ行: 右に今の値と `caret-up-down`。押すと行の右下に右端を揃えたポップオーバーに選択肢が並び、選んでいる行にチェック。外を押すと背面の透明な板が受けて閉じる）/ `sidebar` + `sidebar_item`（サイドバーの行。地は `sidebar`（GNOME 風のツートーン）で背景が無く、選んでいる行だけ文字が `neutral-text` になる。ほかは `neutral-text-low`。左端のアクセント色の印は `sidebar` が 1 つだけ描き、選ぶ行が変わると `Motion::Hop`（ease-out-back）で跳んで移る）/ `surface`）。値は `tokens.json`（色は Radix Colors を OKLCH にしたもの）が唯一の情報源で、build.rs が `palette` クレートで sRGB にしてコードを作り、役割の組が WCAG のコントラスト比を満たさなければビルドを落とす

## 主な公開 API

`icon(&icons::HEART).weight(Weight::Fill).size(..).color(..).rotate(..)`（Phosphor を path で描く。色は `Background` なのでグラデーションでアイコンの形に抜ける。6 ウェイト全対応。**ソースで使われているアイコン・ウェイトだけ**を build.rs が埋め込む。データは `icons/*.tsv`、更新は `icons/vendor.mjs`）, `Theme::{DARK, LIGHT, of, current, set_mode, fading, map, zip, grayscale}`（`grayscale` は白黒にしたテーマ。止まったニャプリの画面。`set_mode` でテーマを切り替えると、`Motion` があれば `current` が全役割を前の色から `duration_ms::SLOW` かけて OKLab で補間する。その間 `fading` が真で、`ui` のフレームループは全パネルを描き直す）, `Mode`, `components::{button, icon_button, round_button, switch, slider, panel, card, card_panel, dialog, PANEL_MARGIN, surface, tooltip, Tooltips, hover_tooltip, Variant}`（`Variant::{Default, Primary, Danger, OnBackground, Ghost}`。既定は無彩色。`Ghost` は背景の無いボタン）, `content_button`（中身を足す横長のボタン）, `progress_ring`（線の円の進み具合。上から時計回り）, `scale::*`, `drive::{now, advance, keep_drawing}`（動きの駆動: 時計と再描画の要求。部品は `Instant::now()` を直接読まない）, `cue::{Cue, emit, take, hover, begin_hover}`（効果音の要求。部品は種類 `Cue` を置くだけで音は知らない。同じ種類は 50ms 以内なら捨てる。音の割り当ては `ui::cue`）, `catalog::Catalog`（デバッグ用カタログ。色の段・役割・定数・文字・アイコン・部品・動きを 1 画面で確認する。`cargo run -p design --example catalog`）。見た目の方針は `crates/design/GUIDELINES.md
