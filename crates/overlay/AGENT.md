## 主な公開 API

`Overlay::{set_dock_slot, set_dockable, take_dock_changes, dock_hint}` + `DockHint` + `DOCK_HINT_PX`（下の節）, `Overlay::{add_panel, attach, attach_to_hand, detach, set_locked, set_reach, set_parent, set_hidden, set_nav_bar, set_veil, set_resolution, tick, submit}`, `Parent { panel, carry, dismiss, hud, docked, slot }`（`dismiss` = 子の外側を押すと子を閉じる。ブロックしたい子だけ `PanelSpec::without_dismiss`。`docked` = 親に固定した子で、親を暗くせず入力も止めない。`slot` = 親の上端の上に、子のナビゲーションバーの分を空けて、親から見て指定の角度だけ起こして立てる（子の大きさが変わっても毎 tick 置き直す）。`slot` にはめるときは行き過ぎずに滑らかに動き（`Motion::Move`。ダッシュボードから呼び出したときに跳ね返らない）、外すときは離れたと分かるよう面の向きへ 0.2m 手前に飛び出す（`Motion::Pop`）。固定した組（バー・はめた画面・キーボード）はどれを掴んでも上にはめた画面を掴んだことにし（はめられる画面そのものを掴んだときは磁石で引っこ抜く。「はめた画面を引っこ抜く・はめる」の節）（頭に向けて垂直に立て、ほかは付いてくる。はめた画面が無ければ根元の `grab_anchor`（ダッシュボードは画面が立つ所）を基準にする）、はめた画面は下端を動かさずに大きさを変え、入れ替わりで消える（閉じる・隠す）ときはフェードアウトしながら 0.15m 後ろへ下がる（重なってちらつかないように。隠れたものは外しても手前へ出さない）。ポップオーバー（固定して外側で閉じる子）は前面の描画順。固定した子のナビゲーションバーは頭からの距離で大きさを変えない）, `Overlay::set_lazy_follow` + `LazyFollow`（パネルを頭の向きと歩きにゆるく追従させる。左右の向きだけを見て上下・傾きは見ず（パネルは立ったまま頭の方を向く）、HMD の高さに合わせ、頭から水平に一定の距離を保つ。向きは不感帯（既定 25°）の中なら動かさず、外れたら追いつくまで滑らかに回る（時定数 0.6 秒。位置は 0.3 秒）。取り付けより優先し、掴めない（`Panel::grabbable`。レーザーでの操作はそのまま使える）。純粋な計算（`lazy_follow.rs`）で、`PanelSpec::lazy_follow` / `PanelCommand::LazyFollow` で付ける）, `Overlay::set_resizable`（掴んで大きさを変えられるか。掴んだものと動かすものが違うときも変えない）, `Overlay::set_reach`（取り付けたまま掴んで動かせるのを取り付け先から指定の距離までに限る。掴んでいる間もその外へは出ず、離すとその内で付け直す。`PanelSpec::reach`）, `Overlay::set_locked`（掴んでいる最中にロックすると掴みを取り消す。取り付け中なら掴む前のオフセットへ戻り、掴んでいる間に変えた大きさも戻る）, `Overlay::attach_to_hand`（パネルを手のコントローラに持たせる。レーザーの出る所を根元に、そこから前へ伸ばし（上から見るとコントローラの先に面がある）、手前（天面の側）へ 45°（`HAND_TILT`）起こす。手を起こすと立って表がこちらを向く。地の下端の左右中央を、面に沿って根元から 3cm（`HAND_GAP`。下に付くナビゲーションバーがコントローラに重ならない隙間）の所に置く。長い辺が 0.4m（`HAND_SIZE`。UI スケールが掛かる）より大きければ、縦横比を保ってそこまで縮める（外しても戻さない）。オフセットは縮めた後の大きさで決める。手のコントローラに付いたパネル（とその子・ナビゲーションバー）は、その手のレーザーでは指さない（レーザーと一緒に動くので、根元の近くのバーに誤って当たるだけ。ほかの手では指せる）), 取り付けたパネルの子・ナビゲーションバーは、根元と同じデバイスに相対で付ける（`follow_roots`。根元はランタイムが合成の直前の姿勢で動かすので、毎 tick の姿勢で置くと遅れて見える）, `Overlay::set_grab_anchor`（掴んだとき手で動かして頭へ向ける基準。`PanelSpec::grab_anchor`）, `Overlay::set_hidden`（閉じずに隠す。フェードアウトし、入力・暗転の対象外。子も一緒に隠れる）, `Panel::pixel_to_world`, `Overlay::set_os_cursor`（そのパネルを指している手のカーソルを OS ## ファイルの分け方（ルール）

**役割ごとに 1 ファイル**。`lib.rs` には型（`Overlay` / `Panel` / `Parent` など。フィールドはどのファイルからも触る）と、いくつものファイルが使う定数（描画順の表 `*_SORT` など）だけを置き、`Overlay` の振る舞いは下のファイルの `impl Overlay` に書く。1 つのファイルだけが使う定数はそのファイルに置く。テストはそのファイルの子（`hand/tests.rs` など。非公開の項目に触れる）に置き、共通の道具（`setup` / `controller` / `with_child` など）は `test_util.rs`。

| ファイル | 中身 |
|---|---|
| `panels.rs` | パネルを足す・閉じる・隠すと、パネルごとの設定（取り付け・ロック・置き場所・大きさ・ポインタ・取り込み） |
| `options.rs` | 全体の調整（UI スケール・手ブレ抑え・レーザーの長さ・カーソルの大きさ・入力の遮断） |
| `status.rs` | 状態の問い合わせ（パネル・頭と手・指している手・掴んでいる手など） |
| `frame.rs` | 1 フレームの進行（`tick`）・ランタイムへの送り出し・表示のアニメーション・暗転 |
| `hand.rs` | 手ごとの入力（ヒット判定とポインタイベント・手ブレ抑え・掴んで動かす・大きさを変える） |
| `family.rs` | 親子関係（ダイアログ・ポップオーバー・はめる場所）とナビゲーションバーの置き場所 |
| `magnet.rs` | はめた画面を掴んで引っこ抜く・近づけてはめる磁石と、はまる所の見本（`Pointer::Dock`）の置き場所 |
| `pointers.rs` | レーザー・カーソル・ツールチップ・ドラッグの見た目・OS のカーソル |
| `geometry.rs` | 置き場所の計算の小さな道具（`anchored` ほか） |
| `lazy_follow.rs` | 頭へのゆるい追従（`LazyFollow`） |

## はめた画面を引っこ抜く・はめる（磁石）

`Overlay::set_dock_slot(owner, tilt)`（`PanelCommand::DockSlot`。ダッシュボードのバーの上端）が画面をはめる場所で、`Overlay::set_dockable`（`PanelCommand::Dockable`。`ui::PanelSpec::dockable`）の画面そのもの（とそのナビゲーションバー）を掴むと磁石が効く。バー・キーボードを掴んだときは今まで通りダッシュボードごと動く。

- **引っこ抜く**: はまっている画面を掴んで引いても、はまる所から手を `TEAR`（0.18m）離すまでは画面ははまる所から動かない（位置・向き・大きさとも。親も連れていかない）。越えるとその場で親から外れ（`Overlay::take_dock_changes` に `(id, false)`）、手へ飛び出す（`Motion::Pop`）。越える前に離せばはまったまま。
- **はめる**: はめる場所が空いていれば、外れた画面を掴んで近づけると `ATTRACT`（0.35m）から手の位置よりはまる所へ引き寄せられ、`CATCH`（0.1m）で吸い付いてはまる所に収まる（`Motion::Attract`。離すまではまだはまっていない。吸い付いている間は動かず、また `TEAR` 引けば外れる）。吸い付いたまま離すとはまる（`(id, true)`）。ほかの画面がはまっていれば効かない（ナビゲーションバーの `nav-dock` は入れ替える）。
- **見本**（`Pointer::Dock`。手ごと。描画順は幕とパネルの間）: 磁石が効いている間、はまる所の 1cm 奥（`GHOST_SINK`。同じ面だとはまった画面と Z ファイティングする）に、画面の地より `GHOST_PAD`（1cm）ずつ大きく置き（はまっている間も画面の周りに枠が見える）、上に一行の帯（`DOCK_HINT_PX`）を足した解像度にする。何を書くかは `Overlay::dock_hint`（はまっていれば `Pull`、吸い付いていれば `Release`、外れていれば `Attach`）で、`DockHint::docks`（今離すとはまる）で上の層は枠の色も変える。はまる所はナビゲーションバーのはまっている間の大きさ（`nav_bar_size`）で決める（外れたバーは頭からの距離で大きさが変わり、見本が上下に動いてしまう）。置き場所が分かるよう動かさず、濃さ（ランタイムの不透明度）だけを変える: 掴んでいる画面がはまる所から `GHOST_NEAR`（0.35m）より近ければはっきり出し、遠ざかるにつれて薄れ、`GHOST_FAR`（0.7m）より遠ければ消える。掴む・離すときはフェードする。掴み始めは、掴んだ画面に合わせて描き直した絵が届く（`Overlay::submit` で今の縦横比の絵）まで出さない（前の絵を一瞬見せない）。絵は一行が変わったときだけ描き直す。
- ナビゲーションバーやダッシュボードのボタンで外す・はめるときは、外すと手前へ飛び出し（`Motion::Pop`）、はめると行き過ぎずに滑らかに収まる（`Motion::Move`）。
- 距離はどれも目分量（`magnet.rs` の定数）。テスト: `magnet::tests`、実 GPU の E2E は `../ui/tests/gpu/dock_magnet.rs`。

## パネルの表示アニメーション

- VR パネルは中央をアンカーに、サイズ 75%→100%・不透明度 0%→100% で表示し（200ms）、閉じると逆方向に消える（150ms）。
- `animato` で実時間を使って進め、最初の描画が届いてから開始する。途中で閉じても現在の状態から消え、入力は即座に止まる。
- `PanelSpec::without_animation()` で無効化。作成後は `PanelCommand::Animated(false)`、Testing の Animation ボタンでも切り替えられる。レーザー・カーソル・ドラッグ表示は既定で無効。
- フェードは OpenVR の `SetOverlayAlpha`、OpenXR の `XR_KHR_composition_layer_color_scale_bias` で合成し、再生中の画像の再転送を避ける。不透明度 API の無いランタイムだけ、加工前の描画を保持して RGBA を減衰させて転送する。デスクトップの OS ウィンドウは対象外。
- `cargo test -p overlay --test animation_runtime -- --ignored` で起動済み SteamVR でアニメーション画像を検証（HMD 必須）。

## UI スケール

全パネルの VR 上の大きさに掛ける倍率（`Overlay::set_scale` / `scale`。アクセシビリティの設定 `ui_scale`。カーネルが 0.7〜1.5 に収めて渡す）。解像度（中の組み方）は変えず、面の大きさだけを変えるので、どんな倍率でも画面の中が崩れることはない（文字の大きさ・太字化とは別の層で、互いに依らない）。

- **等倍のつもりで書く**: `add_panel` の大きさ、`fit_height` の高さ、`set_grab_anchor` / `move_grab_anchor` の位置は等倍の値を渡し、ここで倍率が掛かる。`Panel::size` は掛けた後の実寸（ヒット判定・LOD・ドラッグの見た目の縮尺は実寸で決まる）。`set_drag` の幅だけは、実寸から作るのでそのまま。
- **開いているパネル**: 倍率を変えると、その場で同じ割合だけ大きさが変わる。親から見た子の位置・ナビゲーションバーの大きさ・掴む基準・親の上端に立てた子との隙間（`SLOT_GAP`）も同じ割合で変わるので、組は相似のまま。
- **動かない点**: ふつうはパネルの中心。掴む基準（`grab_anchor`）を持つパネルは基準が動かない（ダッシュボードは、はめた画面が立つ所を中心に大きくなる）。
- **置き直し**: `Overlay::place`（`PanelCommand::Place`）と開くときの置き場所（`ui::PanelSpec::pose_for`）は、等倍のつもりの姿勢を受け取り、掴む基準が等倍のときと同じ所に来るように置く（`anchored`）。画面の側は倍率を知らなくてよい。
- レーザー・カーソル・ツールチップも同じ倍率で大きくなる（レーザーは太さ）。カーソルにはさらに `set_cursor_scale` の倍率（カーソルの大きさの設定）が掛かる（ツールチップには掛けない）。
- テスト: `scale_*`（大きさと中心・相似・隙間・掴む基準）。
