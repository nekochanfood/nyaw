# crates/overlay

層: 2 オーバーレイ

3 次元空間内におけるパネルの配置計算、VR デバイスへの追従（アタッチ）、空間固定ロック、コントローラレーザーの光線交差判定、ポインタイベント生成、把持による移動、親子関係の管理、および視界全体の暗転演出を担当する。

## パネルの配置と親子関係

各パネルは空間内で独立して配置されるほか、親パネルに対する従属関係（`Parent`）を持つことができる。

- **子パネルの基本挙動**: 子パネルは親パネルの移動に追従する。ダイアログ等の子パネルが開いている間は、親パネルは暗転して操作を受け付けない状態となる。親パネルが閉じられると、すべての子パネルも連動して破棄される。
- **外部クリックによる閉塞 (`dismiss`)**: 子パネルの外側をクリックした際に自動的に閉じるかどうかの制御。
- **ドッキング固定 (`docked`, `slot`)**: ダッシュボードのバーなど、親の上端に角度を付けて固定される子パネル。親を暗転させず、独立した操作を受け付ける。ドッキング時は滑らかに移動し（`Motion::Move`）、切り離し時は手前へ 0.2m 飛び出す演出（`Motion::Pop`）を行う。
- **スタック配置 (`stack`)**: 通知パネルなど、ドッキング中の画面の上部に積み重なるように配置される子パネル。先行する画面の出入りに追従して位置を調整する。

## ナビゲーションバーの空間管理

パネルに付随するナビゲーションバーは、持ち主となるパネルの下端中央に上端中央を揃えて毎フレーム配置される。

- **視距離によるスケール補正**: ユーザー頭部からの距離に比例してバーの空間寸法を拡大縮小し、視界内における見かけの大きさと操作性を一定に保つ。
- **自動格納とリソース返還**: 持ち主パネルおよびバーが 1.5 秒間レーザーで指されなかった場合、バーは細い線状に縮退し、1 秒かけてフェードアウトする。消去完了後は VR ランタイムのオーバーレイハンドルを一時的に返還（`Surface::park`）し、ランタイム側のリソース消費を抑える。再び領域を指すと同一の描画順で即座に復帰する（`Surface::restore`）。

## 空間暗転演出（ベール）と入力遮断

ダッシュボード表示時などに視界全体を暗転させる演出（`set_veil`）。

- **暗幕の配置**: 暗転が要求された場合、頭部正面 50m（描画順 0、最奥）に黒幕を配置し、対象パネルの出入りアニメーションと同期させて不透明度を遷移させる。
- **ゲーム入力の遮断**: 暗転中は、背後で動作しているゲームへのコントローラ入力を遮断する（`set_block_input`）。OpenVR 環境では SteamVR Input の全体優先度（`globalActionSetPriority`）を一時的に引き上げてオーバーレイ側で入力を専有する。

## ドッキングと磁石吸着挙動（はめた画面を引っこ抜く・はめる）

ダッシュボードのバー（`set_dock_slot`）と、ドッキング可能な画面パネル（`set_dockable`）との間には、磁石のような吸着・分離挙動が適用される。

- **引っこ抜き（分離）**: ドッキング中の画面を掴んで引っ張った場合、手がスロット位置から 0.18m（`TEAR`）離れるまでは画面はスロットに留まる。この距離を超えた瞬間にドッキングが解除され、手元へ飛び出す（`Motion::Pop`）。ただし、サイズ変更中（掴んだままトリガーを押している間など）は、手が離れてもドッキングを解除しない。解除までの距離は、サイズ変更を終えた時点の位置から測る。
- **吸着（ドッキング）**: 分離した画面を掴んだ状態で空いているスロットへ近づけると、0.35m（`ATTRACT`）の距離から引き寄せが始まり、0.1m（`CATCH`）まで接近した時点でスロット位置へ吸着する（`Motion::Attract`）。吸着状態のまま手を解放するとドッキングが成立する。
- **ドック見本の表示**: 吸着が機能している間、スロット位置の 1cm 奥に半透明のガイド枠（`Pointer::Dock`）を表示し、現在の状態（引っこ抜き可能、解放でドッキング成立など）に応じたヒント枠を表示する。

## 頭部追従（LazyFollow）と手首把持（AttachToHand）

- **頭部緩慢追従 (`LazyFollow`)**: セットアップ画面などでパネルを頭部の向きと移動に緩やかに追従させる機構。水平方向の向きのみを監視し、不感帯（25 度）を外れた場合に時定数 0.6 秒で追いつくように回転する。上下の傾きには追従せず、パネルは垂直に正対し続ける。
- **コントローラ把持 (`attach_to_hand`)**: パネルを手のコントローラ先端へ持たせる配置。レーザー照射口を基準として前方へ伸ばし、手前方向へ 45 度起こして配置する。寸法が 0.4m を超える大型パネルは、視界を塞がないよう比率を維持して縮小される。把持されている側の手からはレーザー判定を除外する。

## UI スケール

アクセシビリティ設定（`ui_scale`、0.7〜1.5 倍）を空間上のパネル寸法に反映する。

- **面の物理寸法の変更**: パネルの内部ピクセル解像度や組み方を変更せず、3 次元空間におけるパネルの物理サイズのみを拡大縮小する。そのため、どのような倍率であっても UI レイアウトの崩れは発生しない。
- **基準点（アンカー）の維持**: 通常のパネルは中心を基準にスケールするが、掴む基準点（`grab_anchor`）を持つパネルは基準点の空間位置を維持したまま拡大縮小する。

## 主な公開 API

```rust
Overlay::{
    add_panel,         // 新規パネルの登録
    attach,            // デバイスへの取り付け
    attach_to_hand,    // 手のコントローラへの把持配置
    detach,            // 取り付けの解除
    set_locked,        // 掴み移動のロック
    set_reach,         // アタッチ追従中の把持可能範囲の制限
    set_parent,        // 親子関係の設定
    set_hidden,        // 不可視化の切り替え
    set_nav_bar,       // ナビゲーションバーの関連付け
    set_veil,          // 空間暗転（ベール）の有効化
    set_resolution,    // パネル解像度の更新
    set_dock_slot,     // ドッキングスロットの設定
    set_dockable,      // ドッキング可能フラグの設定
    set_lazy_follow,   // 頭部追従の設定
    set_scale,         // UI スケールの設定
    gazed,             // ユーザー視線の注視判定
    tick,              // 1フレームの姿勢計算と交差判定
    submit,            // ランタイムオーバーレイへの転送
};
```

## ファイル構成と責務

| ファイル | 責務と実装内容 |
|---|---|
| `panels.rs` | パネルの生成、破棄、可視性、およびアタッチ・ロック状態の管理。 |
| `options.rs` | UI スケール、手振れ補正、レーザー長、カーソル倍率などの全体設定。 |
| `status.rs` | パネル姿勢、デバイス姿勢、注視状態などの状態問い合わせ。 |
| `frame.rs` | 毎フレームの更新ループ（`tick`）、ランタイム転送、ベール暗転演出。 |
| `hand.rs` | コントローラ入力処理、光線交差判定、掴み移動、寸法変更。 |
| `family.rs` | 親子関係（ポップオーバー、ダイアログ）およびナビゲーションバーの配置計算。 |
| `magnet.rs` | ドッキング画面の引っこ抜き・吸着判定（磁石挙動）とガイド枠表示。 |
| `pointers.rs` | レーザー光線、カーソル、ツールチップ、OS カーソルの空間描画。 |
| `lazy_follow.rs` | 頭部追従（`LazyFollow`）の回転・位置補間計算。 |
