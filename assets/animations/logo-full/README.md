# フルロゴのイントロアニメーション

`assets/logos` のフルロゴ（Light と Dark）が組み上がるイントロを、Lottie の JSON にしたもの。60fps、180 フレーム（3 秒）。最後のフレームは静止画のロゴと同じ見た目になる。

| ファイル | 内容 |
| --- | --- |
| `logo-full-light.json`, `logo-full-dark.json` | 生成された Lottie。アプリやサイトはこれを読む |
| `build.mjs` | JSON を生成するスクリプト（依存なし） |
| `review.html`, `review.mjs` | レビュー用のページと、それを配信するサーバー |

## 生成とレビュー

```sh
node assets/animations/logo-full/build.mjs    # JSON を作り直す
node assets/animations/logo-full/review.mjs   # http://localhost:4173/animations/logo-full/review.html を開く
```

レビューのページでは、再生と一時停止、フレーム単位のシーク、速さの変更、テーマの切り替えができ、隣に静止画のロゴを並べて最後のフレームと見比べられる。`?theme=dark&frame=40` を付けると、そのフレームで止まり操作部が隠れるので、ヘッドレスのブラウザーで撮影できる。lottie-web は CDN から読む。

形と色は `assets/logos` の SVG から読むので、ロゴを描き直したら `build.mjs` を実行し直す。ただし、どのサブパスがどの部品（文字、耳、しっぽ）かという対応は `build.mjs` の `PARTS` と `TAIL_PATH` に添字で書いてあり、パスの順番が変わったらここも直す。しっぽの輪郭のどのセグメントが下の縁と上の縁かも、`tailSpine` に決め打ちしてある。

## 動きの構成

不透明度は一度も動かさない。見え隠れはすべて、拡大縮小、トリム、変形、切り抜きで表す。

- 文字: n、y、a、w、に、ゃ、う の順に一文字ずつ、0 から行き過ぎて戻る拡大と、少しの回転で出てくる。
- 耳: 文字の裏から、回りながら下からせり上がって出てくる。出始めは文字に隠れるので、現れる瞬間は見えない。そのあと付け根を中心に何度かぴくっと動く。
- しっぽ: 芯線（根元と先端の 2 頂点の 3 次ベジェ）を太い線で描く。出始めは、根元の制御点のハンドルの向きを逆に辿った w の裏の点に、少し縮めて隠しておく。そこからハンドルの向きに沿って滑り出しながら、トリムで circ の in-out で伸びる。同時に、しっぽ全体を根元を中心に、先端を下げた向きからばねで完成形の向きへ回す。勢いのまま完成形を越えて先端が持ち上がり、揺れ返しながら収まる。芯線の形は伸び始めから完成形のまま変えない。芯線は、SVG の輪郭化されたしっぽの両縁の中点に当てはめて作る。
- バブル（地の円）: 元の位置のまわりを回り込みながら漂って収まる。
- 斜めの帯: 幅のある明るい帯が、circ の in-out で左から右へ横切る。ロゴの上を通る時間は、リファレンスと同じ約 0.4 秒にしてある。

層は、手前から「文字」と「耳としっぽ」の 2 段に分かれる。耳としっぽを文字より奥に置き、文字の下から出てくるようにするためで、段ごとに次のものを持つ。最後のフレームでも、耳としっぽと文字のつなぎ目には文字の輪郭の線が残る（静止画では一体になっている）。

- 塗りと輪郭: 段の部品を 1 つのシェイプレイヤーにグループで入れ、塗りとストロークをグループの外に 1 つずつ置いて、全部品にまとめて掛ける。部品の動きはグループのトランスフォームに持たせるので、ストロークの幅は部品の拡大の影響を受けず、ロゴ全体で一定になる。しっぽは開いた線なので、塗りも輪郭も別の層の線として描く。
- バブルと帯: 塗りをアルファマットにして切り抜くので、形の外には出ない。文字は塗りをまとめたプリコンポを、しっぽは塗りと同じ線を型にする。しっぽの型はうねりに合わせて形が変わる。

## 使うときの注意

合成の大きさは、SVG の viewBox の四辺に 24 の余白（`build.mjs` の `MARGIN`）を足したもの。出現の行き過ぎ、耳の回転、しっぽのうねりで、絵がロゴの外形より外へ出るためで、プレイヤーは合成の範囲の外を描かない。静止画と同じ位置と大きさに置くには、余白の分だけ外側に広げて置く（viewBox が 352.49 × 150.19 のとき、合成は小数を切り上げた 401 × 199 になる。左と上には 24 ずつはみ出し、右と下には切り上げの分だけ少し多くはみ出す）。
