# フルロゴのイントロアニメーション

`assets/logos` のフルロゴ（Light と Dark）が組み上がるイントロと、完成形のロゴの部品を押したときの反応を、Lottie の JSON にしたもの。60fps で、イントロは 180 フレーム（3 秒）。最後のフレームは静止画のロゴとほぼ同じ見た目になる（違いは「層の構成」を参照）。

| ファイル | 内容 |
| --- | --- |
| `logo-full-light.json`, `logo-full-dark.json` | 生成された Lottie。アプリやサイトはこれを読む |
| `build.mjs` | JSON を生成するスクリプト（依存なし） |
| `review.html`, `review.mjs` | レビュー用のページと、それを配信するサーバー |
| `export.html`, `export.mjs` | MP4 と WebP に書き出すページとスクリプト |
| `logo-full-light.webp` | リポジトリの README に貼るアニメーション（生成物） |

## 生成、レビュー、書き出し

```sh
node --run logo:webp                          # JSON と README 用の WebP を作り直す
node --run logo:review                        # http://localhost:4173/animations/logo-full/review.html を開く
node assets/animations/logo-full/build.mjs    # JSON だけを作り直す
node assets/animations/logo-full/export.mjs   # JSON を作り直し、out/ に MP4 を書き出す
```

`pnpm run` でも動くが、依存のインストールが先に走ることがある。これらのスクリプトに依存はないので、`node --run` を使う。

レビューのページでは、再生と一時停止、フレーム単位のシーク、速さの変更、テーマの切り替えができ、隣に静止画のロゴを並べて最後のフレームと見比べられる。`?theme=dark&frame=40` を付けると、そのフレームで止まり操作部が隠れるので、ヘッドレスのブラウザーで撮影できる。

MP4 の書き出しは、ヘッドレスの Chrome でレビューのページと同じ描画を 1 フレームずつ PNG にし、ffmpeg で動画にまとめる。Chrome と ffmpeg が要る（Chrome の場所は環境変数 `CHROME` で変えられる）。テーマを `light` か `dark` で指定でき、省くと MP4 は両方、WebP は light だけを書き出す。`--scale` で倍率（既定は MP4 が 2 倍、WebP が 1.5 倍）、`--bg` で背景色を変えられる。MP4 は透明を持てないので背景色を敷き、既定はレビューのページの背景と同じ色にする。出力先の `out/` は Git に入れない。

GitHub の README は Lottie を再生できないので、`node --run logo:webp`（`export.mjs --webp`）で透過のアニメーション WebP を書き出して貼る。60fps で 1 回だけ再生して完成形で止まる。GitHub ではテーマに合わせた画像の切り替えが効かないことがあるので、light に固定する。ロゴを描き直したり動きを変えたりしたら、これも作り直す。

lottie-web は、レビューと書き出しのページが CDN から読む。

形と色は `assets/logos` の SVG から読むので、ロゴを描き直したら `build.mjs` を実行し直す。ただし、どのサブパスがどの部品（文字、耳、しっぽ）かという対応は `build.mjs` の `PARTS` と `TAIL_PATH` に添字で書いてあり、パスの順番が変わったらここも直す。しっぽの輪郭のどのセグメントが下の縁と上の縁かも、`tailSpine` に決め打ちしてある。動きの時間や大きさは、`build.mjs` の先頭の設定にまとめてある。

## 動き

不透明度は一度も動かさない。見え隠れはすべて、拡大縮小、トリム、回転、マスク、マットで表す。

- 全体の位置: しっぽが出るまでは、文字と耳を左右の中央に置く。しっぽが w から出てくるのに合わせて、全体を easeInOutCubic で左へ動かし、静止画のロゴと同じ位置に収める。
- 文字: n、y、a、w、に、ゃ、う の順に一文字ずつ、0 から行き過ぎて戻る拡大と、少しの回転で出てくる。
- 耳: 下にある文字が出そろってから、文字の裏から回りながらせり上がって出てくる。そのあと付け根を中心に何度かぴくっと動く。
- しっぽ: 芯線（根元と先端の 2 頂点の 3 次ベジェ）を太い線で描く。芯線は、SVG の輪郭化されたしっぽの両縁の中点に当てはめて作り、形は最後まで変えない。
  - 出始めは、根元のハンドルの向きを根元から逆に辿った w の裏の点に隠しておく。
  - そこからハンドルの向きに沿って滑り出しながら、トリムで circ の in-out で伸びる。塗りの線の太さは 20% から 20 フレームかけてイーズインで戻すので、w と「う」の間から見え始めるときはまだ細めで、出てきてすぐに十分な太さになる。輪郭の幅は、太さによらずロゴの他の部品と同じにする。
  - 同時に、しっぽ全体を根元を中心に回す。先端を下げた向きから、ばねで完成形の向きへ戻す。最初の振りは速く鋭く、そのあとの揺れ返しはゆっくり小さく収まる。
- バブル（地の円）: 元の位置のまわりを回り込みながら漂って収まる。
- 斜めの帯: 幅のある明るい帯が、circ の in-out で左から右へ横切る。ロゴの上を通る時間は、リファレンスと同じ約 0.4 秒にしてある。

## 区間と、押したときの反応

1 つの合成に、イントロと反応の区間を並べ、それぞれにマーカー（`markers`）で名前を付けてある。プレイヤーは、名前で区間を選んで再生する（lottie-web なら `playSegments`）。区間の並びと長さは `build.mjs` の `REACTIONS` で決まる。

| マーカー | 内容 |
| --- | --- |
| `intro` | イントロ（0〜180 フレーム） |
| `twitch-<部品>` | 完成形のロゴの部品を押したときの反応。どれも完成形から始まり完成形で終わる |

反応する部品は、文字（`n`、`y`、`a`、`w`、`ni`、`ya`、`u`）、耳（`earL`、`earR`）、しっぽ（`tail`）。文字は縦に縮んでから伸び、少し揺れて戻る。耳は付け根を中心にぴくっと動き、しっぽは先端をぴくっと持ち上げて揺れ返す。

押した部品を見分けるため、一番手前に、部品と同じ形と動きの「押せる範囲」の層を置く。塗り（しっぽは線）の不透明度を 0 に固定して見えなくし（動かさない）、その項目の `cl` に `intro-hit <部品>` を入れる。lottie-web の SVG で描くと、これが path の class になるので、押された要素から `.intro-hit` を辿れば部品がわかる。SVG では、透明でも塗りや線があれば押した位置を拾える。

レビューのページは、イントロの区間を再生し、再生し終えたら部品を押して反応を確かめられる。MP4 に書き出すのはイントロの区間だけ。

## 層の構成

合成の直下にあるのは、全体を左右に動かすプリコンポの層（`scene`）1 つだけである。その中の層は、手前から「文字」と「耳としっぽ」の 2 段に分かれる。耳としっぽを文字の輪郭より奥に置き、文字の下から出てくるようにするためである。そのため、最後のフレームでも、耳としっぽと文字のつなぎ目には文字の輪郭の線が残る（静止画では一体になっている）。段ごとに次のものを持つ。

- 塗りと輪郭: 段の部品を 1 つのシェイプレイヤーにグループで入れ、塗りとストロークをグループの外に 1 つずつ置いて、全部品にまとめて掛ける。部品の動きはグループのトランスフォームに持たせるので、ストロークの幅は部品の拡大の影響を受けず、ロゴ全体で一定になる。しっぽは開いた線なので、塗りも輪郭も別の層の線として描く。
- バブルと帯: 塗りをアルファマットにして切り抜くので、形の外には出ない。文字と耳は塗りをまとめたプリコンポを、しっぽは塗りと同じ線を型にする。合成の端では、型の切り抜きの境目からバブルが細い線になって漏れることがある（描く位置が端数のピクセルのとき）ので、バブルと帯の層には、合成の端から少し内側だけを描くマスクも掛ける。

奥の段には、見えてよい範囲だけを残すマスクを掛ける。耳は文字の上端より少し下の線から上、しっぽは w の右端より少し左の線から右だけが見える。文字がまだ小さいときや文字の隙間からも、裏に隠した耳としっぽは見えない。

## 使うときの注意

合成の大きさは、SVG の viewBox の四辺に 24 の余白（`build.mjs` の `MARGIN`）を足したもの。出現の行き過ぎ、耳の回転、しっぽの揺れで、絵がロゴの外形より外へ出るためで、プレイヤーは合成の範囲の外を描かない。静止画と同じ位置と大きさに置くには、余白の分だけ外側に広げて置く（viewBox が 352.49 × 150.19 のとき、合成は小数を切り上げた 401 × 199 になる。左と上には 24 ずつはみ出し、右と下には切り上げの分だけ少し多くはみ出す）。
